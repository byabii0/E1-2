**Python 기초**

- [ ] 변수가 무엇이고, 왜 사용하는지 설명할 수 있다.
      
      변수: 데이터에 이름을 붙여 저장합니다. 데이터를 재사용하고, 코드의 의미를 쉽게 파악하기 위해 사용합니다.
      
- [ ] int, str, bool, list, dict의 차이를 설명할 수 있다.

      int: 정수 (1, 100)
      str: 문자열 ("Hello")
      bool: 참/거짓 (True, False)
      list: 순서가 있는 목록 ([1, 2, 3])
      dict: 키-값 쌍으로 이루어진 사전 ({"name": "AI"})
      
- [ ] if/elif/else로 조건에 따라 다른 동작을 수행할 수 있다.

      if: 만약 ~라면(조건) 결과입니다.
      elseif: 조건이 여러개일 때 사용합니다.
      else: 어떤 조건에도 해당하지 않을 때 사용합니다.

      예시

       score = 85
           
      if score >= 90:
          print("A학점입니다!")  # 조건이 참(True)일 때 실행
      elif score >= 80:
          print("B학점입니다!")  # 위 조건이 거짓이고, 이 조건이 참일 때 실행
      else:
          print("C학점 이하입니다.") # 모든 조건이 거짓일 때 실행

**비교 연산자와 논리 연산자**

      비교 연산자: ==(같다), != (다르다), > (크다), < (작다), >= (크거나 같다), <= (작거나 같다)
      논리 연산자: and: 두 조건이 모두 참일 때, or: 두 조건 중 하나라도 참일 때, not: 조건을 반대로 뒤집을 때 (True -> False)

**주의해야 할 규칙**

      콜론(:): if, elif, else 줄 끝에는 반드시 콜론을 붙여야 합니다.
      들여쓰기(Indentation): 조건문 안에서 실행될 코드는 반드시 한 탭(또는 공백 4칸)을 들여써야 합니다. 파이썬은 들여쓰기로 코드의 범위를 구분하기 때문입니다.
      
- [ ] for와 while의 차이를 설명하고 적절히 선택할 수 있다.

      for, while은 반복문입니다.
      for: 정해진 횟수나 리스트의 요소만큼 반복할 때(예: 리스트의 모든 아이템 출력) 사용합니다.
      while: 특정 조건이 참인 동안 계속 반복할 때(예: 사용자가 '종료'를 입력할 때까지) 사용합니다.
      
- [ ] 함수를 정의하고, 매개변수와 반환값을 활용할 수 있다.

      반복되는 코드를 하나로 묶은 기능 단위입니다. 매개변수로 재료를 받고, 반환값(return)으로 결과를 내보냅니다.
      일반 변수는 필요할 때 코드 아무 곳에서나 만들어서 쓸 수 있지만, 매개변수는 함수 내부에서만 사용 가능합니다.
      반환값은 함수가 모든 작업을 마친 후 호출한 자리로 돌아오는 결과값입니다.

      예시

      def plus(a, b):
          return a + b
      
      # 1. 처음 코드
      result = plus(1, 2) 
      
      # 2. 함수가 실행된 후 (반환값이 '호출한 자리'로 돌아옴)
      result = 3 

**클래스와 객체**

- [ ] 클래스가 무엇이고, 왜 사용하는지 설명할 수 있다.

      클래스: 객체를 만들기 위한 설계도입니다. 관련된 데이터와 기능을 하나로 묶어 관리하기 위해 사용합니다.
      객체: 설계도를 보고 실제로 만든 실체입니다.

- [ ] __init__ 메서드와 self의 역할을 설명할 수 있다.

      __init__: 객체가 생성될 때 자동으로 실행되는 초기화 함수입니다.
      self: "나 자신"을 가리킵니다. 클래스 내부에서 자기 자신의 변수나 메서드에 접근할 때 사용합니다.

- [ ] 클래스의 속성(attribute)과 메서드(method)를 정의하고 활용할 수 있다.

      속성(Attribute): 객체가 가지고 있는 정보(변수)입니다.
      메서드(Method): 객체가 할 수 있는 동작(함수)입니다. 

**파일 입출력**

- [ ] 파일을 열고, 읽고, 쓰는 기본 과정을 설명할 수 있다.

      open()으로 파일을 열고, read/write로 내용을 읽거나 쓴 뒤, 반드시 close()로 닫아줘야 합니다. (파이썬의 with문을 쓰면 자동으로 닫힙니다.)

- [ ] JSON 형식이 무엇이고, 왜 데이터 저장에 사용하는지 설명할 수 있다.

      데이터를 저장하는 표준 형식입니다. 텍스트 형태라 사람이 읽기 쉽고, 파이썬의 dict와 구조가 비슷해 프로그램 간 데이터 교환에 유리합니다.

- [ ] try/except를 사용하여 오류를 처리할 수 있다.

      예외 처리(try/except): 프로그램 실행 중 발생할 수 있는 에러(파일 없음, 숫자 입력 오류 등)를 미리 대비하여 프로그램이 갑자기 꺼지지 않게 막아줍니다.

**Git 기초**

- [ ] Git이 무엇이고 왜 필요한지 설명할 수 있다.

      Git: 코드의 변경 이력을 관리하는 도구입니다. 실수했을 때 과거로 되돌리거나, 여러 명이 협업할 때 필수입니다.

- [ ] init, add, commit, push, pull, checkout, clone이 각각 무엇을 하는지 설명할 수 있다.

      init: 현재 폴더를 Git이 관리하도록 시작합니다.
      add: 변경된 파일을 장바구니에 담습니다(Staging).
      commit: 장바구니에 담긴 변경사항을 기록으로 남깁니다(Snapshot).
      push: 로컬의 기록을 GitHub(원격)으로 올립니다.
      pull: GitHub의 최신 내용을 내 컴퓨터로 가져옵니다.
      checkout: 브랜치를 바꾸거나 과거로 이동합니다.
      clone: 원격 저장소를 통째로 내 컴퓨터에 복사해옵니다.

- [ ] 브랜치를 생성하고 병합할 수 있다.

      브랜치: 원본 코드를 건드리지 않고 새로운 기능만 따로 개발하는 독립된 공간입니다.
      병합(Merge): 브랜치에서 완성된 기능을 다시 메인 코드(main)에 합치는 과정입니다.

- [ ] 원격 저장소를 clone하고, pull로 변경사항을 가져올 수 있다.

      clone: 원격 저장소에 있는 프로젝트를 내 컴퓨터에 처음으로 내려받을 때 사용합니다. 새로운 폴더가 생깁니다.
      pull: 이미 내 컴퓨터에 저장소가 있는 상태에서, 원격 저장소에 새로 올라온 변경 사항만 내 컴퓨터로 합칠 때 사용합니다. 기존 폴더의 내용이 바뀝니다.

git 저장소 설정: 과제 조건을 만족하기 위하여 수행 기록을 따로 정리했습니다.

# 공통 입력/예외 처리 기준(최소 요구)

**공통 입력 요소**

입력 항목 ㅣ 입력되는 위치 ㅣ 데이터 형식
   
메뉴 번호 ㅣ 메인 메뉴 화면 (choice) ㅣ 문자열 (str)
   
정답 번호 ㅣ 퀴즈 풀기 화면 (ans) ㅣ 정수형 (int)
   
새 문제/보기 ㅣ "퀴즈 추가 화면 (q, c)" ㅣ 문자열 (str)
   
새 정답 번호 ㅣ 퀴즈 추가 화면 (a) ㅣ 정수형 (int)

**공통 입력 처리 기준**

모든 입력은 터미널 콘솔의 input() 함수를 통해 받으며, 입력받은 데이터를 처리할 때 아래 3가지 규칙을 공통으로 적용합니다.
   
문자열 입력 받기 (input()): 사용자로부터 텍스트 입력을 받아 변수에 저장합니다.
   
타입 변환 및 예외 검사 (int()): 정답 번호나 메뉴 입력 시 숫자로 변환하며, 문자 입력 시 에러가 나지 않도록 try-except로 감쌉니다.
   
입력값 범위 검증 (Validation): 정답 번호는 1번-4번 범위 내인지, 메뉴 번호는 1번-5번 범위 내인지 검사합니다.

**예외 입력 요소**

예외 입력 요소 ㅣ 발생 위치 ㅣ 사용자의 예외 입력 행동 ㅣ 발생할 수 있는 에러/문제점
   
문자/특수문자 입력 ㅣ "play_quiz, add_quiz (정답 번호 입력 시)" ㅣ 숫자가 필요한 곳에 "abc", "#" 등 입력 ㅣ int() 변환 실패로 ValueError 발생하여 프로그램 강제 종료
   
범위 밖의 숫자 입력 ㅣ "play_quiz, add_quiz, 메뉴 선택" ㅣ 보기가 1-4번인데 0, 5, -1 등 입력 ㅣ 존재하지 않는 정답 처리 또는 논리적 오류 발생
   
공백/빈 문자열 입력 ㅣ 모든 input() 창 ㅣ 아무것도 입력하지 않고 Enter만 입력 ㅣ 문제 내용이나 보기가 빈 값("""")으로 저장됨
   
메뉴 입력 오류 ㅣ 메인 메뉴 (choice) ㅣ 1-5번 이외의 문자/숫자 입력 ㅣ 잘못된 메뉴 선택으로 인한 오작동

**예외 처리 기준**

발생 위치 ㅣ 입력 대상 ㅣ 발생 가능한 예외/상황 ㅣ 처리 기준 및 대응 로직
   
메인 메뉴 ㅣ 메뉴 번호 (1-5) ㅣ "문자 입력, 범위 밖 숫자(0, 6 등), 공백" ㅣ else 블록에서 "잘못된 입력입니다." 출력 후 메뉴 재출력
   
퀴즈 풀기 ㅣ 정답 번호 ㅣ 문자 입력 (ValueError) ㅣ try-except로 예외를 잡아 오답 처리 및 안내 문구 출력
   
퀴즈 추가 ㅣ 퀴즈 질문/보기 ㅣ 빈 문자열 (Enter만 입력) ㅣ .strip() 적용 및 공백 시 재입력 유도
   
퀴즈 추가 ㅣ 정답 번호 ㅣ 문자 입력 또는 1-4 범위를 벗어난 숫자 ㅣ 1 <= ans(사용자가 입력한 답의 변수) <= 4 조건 검증 및 예외 발생 시 재입력 루프
